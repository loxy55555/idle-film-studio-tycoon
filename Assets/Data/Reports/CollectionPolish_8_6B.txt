1. ELIMINAR BOTONES HUÉRFANOS
=====================================================================
Estado: PASS

Problema: MovieCollectionUI era un componente añadido sobre ColeccionPanel
que ya tenía hijos de la build anterior (botones de filtro por género,
encabezados, contenido de album, etc.). Al llamar BuildAllLevels() sin
limpiar, el contenido nuevo se añadía encima del antiguo.

Fix en MovieCollectionUI.BuildAllLevels():
  // Phase 8.6B: remove any legacy children (orphan filter buttons, old grids)
  for (int i = root.childCount - 1; i >= 0; i--)
  {
      var ch = root.GetChild(i);
      if (Application.isPlaying)  Object.Destroy(ch.gameObject);
      else                        Object.DestroyImmediate(ch.gameObject);
  }

Cualquier botón, panel o texto que existiera antes de BuildAllLevels()
es eliminado antes de construir el nuevo layout. El componente arranca
desde cero, garantizando pantalla limpia.

3. PELÍCULAS ORDENADAS POR RAREZA
=====================================================================
Estado: PASS

Implementado en PopulateMovieGrid() antes de construir las filas:
  filtered.Sort((a, b) => RarityOrder(b.rarity).CompareTo(RarityOrder(a.rarity)));

Función de orden:
  Legendary = 3  (primeras)
  Epic      = 2
  Rare      = 1
  Common    = 0  (últimas)

Agrupación visual resultante dentro de cada género:
  ┌────────────────────────────────────────────────┐
  │ ★ ★ ★   ← Legendarias (marco dorado brillante)│
  │ ◆ ◆ ◆   ← Épicas (marco morado)               │
  │ ● ● ●   ← Raras (marco azul)                  │
  │ · · ·   ← Comunes (marco gris)                │
  └────────────────────────────────────────────────┘

Las Legendarias y Épicas aparecen primero → el jugador ve inmediatamente
las películas más valiosas y sabe cuáles le faltan.
