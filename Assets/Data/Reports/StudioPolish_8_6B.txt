1. BOTÓN DE AJUSTES (⚙)
=====================================================================
Estado: PASS (ya activo desde 8.5C, confirmado en 8.6B)

Implementación en:
  DefinitiveHudBootstrap.PatchTopBarSettingsButton()
  TopBarUI.PatchSettingsIcon()

La función busca cualquier botón cuyo nombre contenga "SETTING", "MENU",
"HAMB" o "SETTINGSBTN" dentro del TopBarUI y actualiza su label TMP a "⚙".
Se ejecuta cada sesión de Play para garantizar el estado correcto.

No se ha modificado la posición absoluta del botón (eso requeriría saber
la jerarquía exacta del baked scene). El icono correcto ya aparece en
la esquina superior derecha según el layout del builder.

2. TABS DEL ESTUDIO — ANCHURA COMPLETA
=====================================================================
Estado: PASS (nuevo en 8.6B)

Implementación:
  DefinitiveHudBootstrap.PatchStudioSubTabs(switcher)
  Ejecutado en ApplyBakedSceneVisualPatches() cada Play.

Cambios aplicados a todos los objetos que terminan en "SubTabBar" o "TabBar"
dentro del EstudioPanel:

  HorizontalLayoutGroup:
    childForceExpandWidth = true   ← tabs se reparten el ancho completo
    childForceExpandHeight = true
    padding = (0,0,0,0)            ← sin gaps laterales
    spacing = 0                    ← sin espacios entre tabs

  LayoutElement de la barra:
    preferredHeight = 52px         ← antes ~40px (SubTabFontSize)
    minHeight = 48px               ← área táctil mínima garantizada

  Labels (TextMeshProUGUI):
    fontSize = 13px, Bold          ← más legibles en móvil
    enableAutoSizing = false

  Cada botón de tab:
    LayoutElement.flexibleWidth = 1  ← todos los tabs se reparten igual
    LayoutElement.preferredWidth = -1  ← anula cualquier ancho fijo previo

Resultado: los tabs DEPARTAMENTOS, MEJORAS, CONTRATOS (y Personal si
existe) ocupan todo el ancho sin espacios vacíos y tienen un mínimo de
48px de altura para pulsar con el dedo.
