ROOT CAUSE (exact)
------------------
PRIMARY — UI bind failure at startup (verified Play Mode):

  ContractsPanelUI._contracts  = NOT BOUND after load
  MovieCollectionUI._studio    = NOT BOUND after load
  GameFeelUI._studio           = BOUND (has Start() fallback Bind)

  Manual reflection call to Bind() on both panels succeeds immediately:
    → ContractsPanelUI renders 3 cards
    → MovieCollectionUI._studio binds to studio

  Difference vs working GameFeelUI (GameFeelUI.cs L57-61):
    GameFeelUI:  OnGameReady += Bind  AND  if (Instance != null) Bind() in Start()
    MovieCollectionUI / ContractsPanelUI: OnGameReady ONLY, no Start() fallback

  ContractsPanelUI poison pattern (ContractsPanelUI.cs L83-87):
    GameHub.OnGameReady -= Bind;   // removes self permanently
    _contracts = GameHub.Instance?.contracts;
    if (_contracts == null) return; // never retries, never Rebuilds

  ContractsPanelUI.OnEnable (L32-35): only Rebuild() if already bound — no Bind retry
  MovieCollectionUI.OnEnable (L31-35): calls Bind() but only when activeInHierarchy
    (parent StudioPanel_COLECCIÓN inactive until user opens sub-tab)

  RESULT for user:
    • Money/rep/state DO update in StudioManager (if FinalizeProduction runs)
    • Collection grid does NOT refresh → “no discovery / no collection update”
    • Contract panel empty → “no contract progress visible”
    • Premiere MAY show (GameFeelUI bound) but user may miss subtle TopBar changes

SECONDARY — Completion without FinalizeProduction (edge case):

  StopAllCoroutines() in Initialize() L195 and ResumeProductions() L686
  kills ProductionRoutine before timer reaches FinalizeProduction.
  File: SaveSystem.cs L229 calls ResumeProductions on every load.
  Symptom: production bar completes visually after reload glitch, zero rewards.

TERTIARY — Premiere silent abort:

  PremiereSequenceController.PresentNext() L77-81:
    if (_overlay == null) { _queue.Clear(); return; }
  Economy still applied; reward/discovery UX may not appear.
