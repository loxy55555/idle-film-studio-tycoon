WHY UI IS EMPTY (ROOT CAUSE)
----------------------------
PRIMARY: ContractsPanelUI.Bind() never succeeds at startup.

  Evidence:
    • Fresh Play Mode: _contracts = NOT BOUND, 0 UI children
    • GameHub.Instance.contracts has 3 active (same frame)
    • Manual Bind() via reflection: BOUND + 3 cards rendered

  Mechanism (ContractsPanelUI.cs L83-87):
    1. GameHub.OnGameReady -= Bind  (removes one-shot retry)
    2. _contracts = GameHub.Instance?.contracts
    3. if (_contracts == null) return  → silent permanent failure

  Missing fallback vs GameFeelUI:
    GameFeelUI.Start() also calls Bind() if GameHub.Instance != null
    ContractsPanelUI has NO Start() fallback

  OnEnable does NOT retry Bind — only Rebuild if already bound.

SECONDARY: Navigation gating (contributes to “invisible” even if bound):
  StudioPanel_CONTRATOS inactive until user opens CONTRATOS sub-tab
  User on DEPARTAMENTOS sees no contracts list (expected UX confusion)

TERTIARY: Layout while inactive (minor):
  First successful Rebuild while panel inactive may need LayoutRebuilder
  after tab activation — not the primary cause (0 children proves no Rebuild)
