[1] VITRINA PRINCIPAL (4 × 7 = 28 posiciones)
=====================================================================
Diseño tipo vitrina de cristal:
  ┌── Marco dorado (FRAME_GOLD, 3px border via VerticalLayoutGroup padding) ─┐
  │ ╔═══════════════════ Interior oscuro (BG_VITRINA) ═══════════════════╗   │
  │ ║  ─── Glass shine: 3px white line (alpha 0.07) at top ───          ║   │
  │ ║  Row 0: ★  ★  ★  ★  ★  ★  ★   ← iluminadas (GOLD_BRIGHT)        ║   │
  │ ║  Row 1: ★  ★  ★  ★  ★  ★  ★   ← iluminadas                      ║   │
  │ ║  Row 2: ☆  ☆  ☆  ☆  ☆  ☆  ☆   ← apagadas (STAR_DIMFG, 40%)     ║   │
  │ ║  Row 3: ☆  ☆  ☆  ☆  ☆  ☆  ☆   ← apagadas                       ║   │
  │ ║  Glass overlay: alpha 0.025 white, ignoreLayout                   ║   │
  │ ╚════════════════════════════════════════════════════════════════════╝   │
  └───────────────────────────────────────────────────────────────────────────┘

Efectos visuales (UGUI puro, sin 3D):
  - Marco FRAME_GOLD (borde dorado mediante padding 3px)
  - BG_VITRINA muy oscuro (0.05, 0.05, 0.10) — fondo de vitrina
  - Glass shine: franja blanca 3px alpha 0.07 en el borde superior
  - Glass overlay: panel blanco alpha 0.025 que cubre toda la vitrina
  - Estrella ganada: fondo GOLD_GLOW (amber 30% alpha) + "★" GOLD_BRIGHT
  - Estrella pendiente: fondo STAR_DARK 60% alpha + "★" STAR_DIMFG (gris)
  - Celdas de 62px de alto, distribuidas equitativamente en 7 columnas

Coherencia con el brief:
  ✓ Cristal: glass shine + glass overlay
  ✓ Profundidad: marco dorado + interior más oscuro
  ✓ Iluminación: GOLD_GLOW + GOLD_BRIGHT para las ganadas
  ✓ Apagadas: visibles pero claramente inertes (gris semi-transparente)
  ✓ 28 huecos siempre visibles

DOTween-READY ARCHITECTURE
=====================================================================
Método stub implementado:
  void AnimateStarEarned(int slotIndex)
    → Debug.Log("[ShowcaseUI] AnimateStarEarned slot=N — DOTween hook ready")
    → Called from OnOscarGained event handler

Para añadir la animación real:
  1. Importar DOTween
  2. En AnimateStarEarned(slot):
     a. _starGlows[slot].transform.localScale = Vector3.zero;
        _starGlows[slot].transform.DOScale(1.2f, 0.3f).SetEase(Ease.OutBack);
     b. DOVirtual.DelayedCall(0.15f, () =>
        _starGlows[slot].transform.DOScale(1f, 0.15f));
     c. _starLabels[slot].DOColor(GOLD_BRIGHT, 0.2f);
