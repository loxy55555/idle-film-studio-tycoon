WHAT EVENT CLOSES THE TUTORIAL?
================================================================

The tutorial FULLY closes (never returns) only via CompleteFtue():

  Trigger                              | Reason string              | Line
  -------------------------------------|----------------------------|------
  OnPremiereDismissed                  | premiere_dismissed         | L279
  CompleteFallbackRoutine              | premiere_unavailable       | L310
  CompleteFallbackRoutine              | premiere_ended             | L316
  CompleteFallbackRoutine              | fallback_timeout           | L326
  SkipAll (skip button)                | skip                       | L357
  ShouldAutoComplete (on load)         | auto_complete_profile      | L74
  ResumeStep FirstMovieComplete+done   | resume_first_movie_done    | L144

OnStudioGuideContinue (green FTUE button) does NOT complete the tutorial.
It only hides the overlay:

  FtueController.cs L240-245:
    void OnStudioGuideContinue()
    {
        StopTargetWait();
        ClearHighlight();
        _overlay?.Hide();    ← visual only, FTUE still active
    }

If the player presses green Continue on the STUDIO GUIDE step BEFORE
the movie completes: overlay disappears but FTUE remains at step 2.
When the movie later completes, T4→T7 auto-completes FTUE silently.

If the player presses green Continue on the PREMIERE popup:
  OnPremiereDismissed → CompleteFtue("premiere_dismissed")
  Tutorial permanently completed.

If premiere is slow/missing:
  CompleteFallbackRoutine fires after 1.5s → CompleteFtue("premiere_unavailable")
  Tutorial permanently completed WITHOUT any button press.

================================================================
WHY THE TUTORIAL "DISAPPEARS" — ROOT CAUSES
================================================================

ROOT CAUSE 1: OnStudioGuideContinue hides overlay without completing FTUE

  File: FtueController.cs L240-245
  Player clicks green Continue on "improve studio" message.
  Overlay vanishes → player thinks tutorial is done.
  FTUE is still active (_step=2 or transitioning to 3).
  No PersistStep on continue — step may desync from player expectation.

ROOT CAUSE 2: FASE 7.1 auto-complete fires aggressively after first movie

  File: FtueController.cs L295-327 (CompleteFallbackRoutine)
  File: FtueController.cs L258-273 (OnMovieCompleted → StartCompleteFallback)

  After first movie, FTUE auto-completes via:
    • premiere dismiss (intended)
    • 1.5s grace if premiere unavailable (may fire while player still
      reading studio guide or premiere)
    • premiere ended detection

  Player perception: "I clicked a button and the tutorial vanished"
  Actual: CompleteFtue() was triggered by premiere_dismissed OR
          premiere_unavailable/premiere_ended fallback, not by the
          studio guide Continue handler.

ROOT CAUSE 3: OnMovieCompleted hides overlay at step 2 without transition UI

  File: FtueController.cs L271
  When movie completes during StudioDuringProduction, overlay is hidden
  immediately (_overlay?.Hide()) before premiere shows.
  Studio guide message vanishes abruptly; premiere popup replaces it.
  Player may interpret premiere Continue as "tutorial button."

ROOT CAUSE 4: Step 2 overlay + premiere timing overlap

  Studio guide appears on production START (step 2).
  Movie may still be running when premiere appears on completion.
  If player hasn't clicked studio Continue, both messages compete.
  OnMovieCompleted force-hides FTUE overlay regardless.

================================================================
REGRESSION vs FASE 7.1 FIXES
================================================================

FASE 7.1 added CompleteFallbackRoutine to prevent softlock when premiere
is unavailable. Side effect: FTUE now auto-completes 1.5s after first
movie if premiere hasn't started, OR immediately when premiere ends.

Combined with OnStudioGuideContinue only hiding overlay (not advancing
or completing), the player experience is:

  "Tutorial showed studio tip → movie finished → popup appeared →
   I clicked green → everything tutorial-related vanished"

The vanish is caused by CompleteFtue (auto or premiere-triggered), NOT
by OnStudioGuideContinue — unless the player only saw overlay hide without
premiere (partial disappear, FTUE still active until movie completes).
