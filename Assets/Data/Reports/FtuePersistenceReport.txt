WHAT HAPPENS ON GAME LOAD
--------------------------

A. New game (no save file)
   • SaveSystem.Load() returns false — no FtueState.ApplySave() called
   • FtueState defaults: Completed=false, Step=Welcome
   • FtueController.OnGameReady() → tutorial starts from Welcome
   • [FTUE] LoadedCompleted=False  (emitted by FtueState.ApplySave
     defaults are not logged, but FtueController logs state)
   • [FTUE] TutorialStarted=       (FtueLog.TutorialStarted)

B. Existing save — ftueCompleted=true
   • FtueState.ApplySave(true, savedStep):
       Completed = true
       Step      = Done  (forced, regardless of savedStep)
   • FtueController.OnGameReady() → FtueState.Completed == true
       → HideOverlayImmediate(), return
       → [FTUE] TutorialSkipped=
   • NO overlay created, NO tutorial shown, NO UI blocked
   • All rules for completed=true: SATISFIED

C. Existing save — ftueCompleted=false, step=N
   • FtueState.ApplySave(false, N):
       Completed = false
       Step      = clamped to [Welcome(0) … FirstMovieComplete(3)]
       (cannot go below 0, cannot exceed 3 while not completed)
   • FtueController.OnGameReady() → ResumeStep(FtueState.Step)
       → tutorial resumes from saved step N
   • Step is NEVER downgraded by ApplySave (old regression bug fixed)

D. Application restart (save already has ftueCompleted=true)
   • Identical to case B: skip fires immediately in OnGameReady
   • No tutorial, no overlay, no blocks
